# Calvin Stahoviak: Resume and CV

The LaTeX source for my one-page resume and full CV, edited in Overleaf.
Every push to `main` rebuilds both PDFs and publishes them at
[calvinstahoviak.com/resume](https://calvinstahoviak.com/resume) and
[calvinstahoviak.com/cv](https://calvinstahoviak.com/cv).

To make your own, start from
[Dual-Resume-CV-Template](https://github.com/cjstahoviak/Dual-Resume-CV-Template).
